# Python-Basic-Movie-Ticket-Booking-System
A simple movie ticket booking system made using python basic functions, list, dictionaries etc.

A simple Python console application that allows users to book movie tickets, select seats, choose seat types, order snacks, and view a complete booking summary.

## Features

* Select a theatre from multiple available screens
* View available seats
* Book one or more seats
* Choose between Normal and Recliner seats
* Add snacks to the order
* Automatic ticket and snack cost calculation
* Detailed booking summary

## Technologies Used

* Python 3
* Lists
* Dictionaries
* Loops
* Conditional Statements
* User Input Handling
